# 积水系统插件

这是一个适用于 Godot 4.4 及以上版本的 2D 世界积水与水面倒影插件。当前发布包仅支持 Windows x86_64，并通过一个 `积水管理器` Autoload 维护动态积水遮罩、倒影视口、脚步涟漪和固定水面纹理。

## 功能

- 根据世界坐标噪声生成无限范围积水。
- 支持指定区域强制生成积水、指定区域排除积水。
- 支持限制全图噪声积水的矩形范围。
- 支持干涸度、边缘柔和度和生成区域圆角。
- 支持脚步涟漪与可独立开关的雨滴涟漪。
- 自动创建倒影视口，并把倒影纹理注入积水和固定水面材质。
- 固定水面使用独立 Shader，可用于河面、湖面或其他静态水域。
- 管理器提供水面检测、脚步涟漪和视口跟随接口。

## 安装与启用

1. 将整个 `addons/积水系统` 文件夹复制到项目的 `addons` 目录。
2. 打开 `项目设置 > 插件`，启用“积水系统”。
3. 插件启用时会自动创建以下 Autoload：

   ```text
   积水管理器 -> res://addons/积水系统/scripts/积水管理器.gd
   ```

4. 固定水面、积水生成区域和排除区域均使用插件自定义节点，不依赖全局分组。

如果项目中没有出现 `积水管理器`，请在 `项目设置 > Autoload` 中手动添加上述路径，并将名称设为 `积水管理器`。

### Windows 原生遮罩构建器

Windows x86_64 发布包已包含 Debug 和 Release GDExtension DLL，管理器会自动使用 C++ 生成遮罩。没有可用 DLL 时会回退到 GDScript，功能仍可使用，但高分辨率或大量区域时性能会明显下降。

本发布包不包含 C++ 源码和 `godot-cpp`。需要自行编译时，请从源码仓库获取 `native` 目录，并在 Visual Studio 开发者命令行执行：

```text
scons platform=windows target=template_debug arch=x86_64 -j8
scons platform=windows target=template_release arch=x86_64 -j8
```

生成的 DLL 应放在 `addons/积水系统/bin/`。其他平台需要按 Godot 官方 GDExtension 构建方式分别编译对应动态库。

## 添加积水画布

1. 在场景中添加 `积水画布`（插件注册的自定义 `Sprite2D` 类型）。
2. 建议将它放在场景根节点或不会被额外缩放的画布节点下。
3. 节点进入场景后会自动注册到管理器。管理器一次只维护一个积水画布。
4. 如果使用自定义材质，必须使用 `shader/积水.gdshader`，并保留 Shader 参数名称；不指定材质时插件会自动创建默认材质。

积水画布会根据当前主视口生成世界遮罩。首次进入场景可能需要几帧完成遮罩计算；遮罩完成前使用黑色安全遮罩，不会显示整屏积水。

## 添加积水区域

创建插件提供的 `积水区域` 自定义节点，并在检查器的 `类型` 枚举中选择：

- `生成`：强制生成积水。
- `排除`：禁止生成积水，优先级高于生成区域。

`积水区域` 继承 `Polygon2D`。绘制顶点后会自动注册到管理器，并自行维护世界顶点、圆角结果和粗略世界包围盒；移动、旋转、缩放、修改顶点或切换类型时会自动刷新。管理器生成遮罩时只提交与当前遮罩范围相交的区域。


## 参数说明

### 积水设置

| 参数 | 作用 |
| --- | --- |
| `积水所用噪声` | `FastNoiseLite` 噪声源；为空时自动创建。 |
| `积水多少` | 噪声阈值，越大积水越多。 |
| `干涸度` | 全局干涸程度，越大积水越少，同时影响指定生成区域。 |
| `积水大小` | 噪声世界尺寸，越大水斑越大。 |
| `积水边缘柔和度` | 统一控制噪声积水、指定生成区域和排除区域边缘的渐变宽度。 |
| `遮罩精度` | 生成遮罩的分辨率，越高越精细但计算量越大。 |
| `遮罩边缘平滑采样` | 对遮罩覆盖率执行距离递减滤波，Shader 以 0.5 为岸线恢复连续抗锯齿轮廓；默认半径 2，0 为关闭。 |
| `遮罩缓冲比例` | 在可见范围外额外生成的遮罩边缘比例；每侧还会叠加 `256` 世界单位固定缓冲，避免相机移动时出现空白闪烁。 |
| `生成区域圆角比例` | 原多边形顶点作为贝塞尔端点；0 时退化为直线，100 时整条边达到最大向内曲率。 |

### 生成范围

| 参数 | 作用 |
| --- | --- |
| `启用全图噪声积水` | 是否在全图按噪声生成积水。关闭后只处理指定生成区域。 |
| `限制全图噪声积水生成范围` | 开启后，仅在下方四个边界组成的矩形内生成全图噪声积水。 |
| `全图噪声积水左/上/右/下边界` | 世界坐标矩形边界；只有启用限制后才在检查器中显示。 |
| `使用积水排除区域` | 是否读取类型为“排除”的 `积水区域` 节点。排除区域优先级高于生成区域。 |
| `排除区域圆角比例` | 原多边形顶点作为贝塞尔端点；0 时为直线，100 时整条边达到最大反向曲率。 |
| `启用指定区域积水` | 是否读取类型为“生成”的 `积水区域` 节点。该区域会强制生成积水，但仍受干涸度影响。 |

区域通常使用 `Polygon2D`，加入对应全局分组即可。生成区域和排除区域重叠时，排除区域优先，不生成积水。

### 水面外观

| 参数 | 作用 |
| --- | --- |
| `水面颜色` | 水面底色，颜色 Alpha 同时控制水面透明度。 |
| `倒影透明度` | 倒影混入水面的强度。 |

### 风吹水纹

| 参数 | 作用 |
| --- | --- |
| `风扰动启用` | 开关风纹及其对倒影的扰动。 |
| `风向` | 风纹传播方向。 |
| `风纹尺寸` | 风纹世界尺寸，越小波纹越密。 |
| `风纹速度` | 风纹动画速度。 |
| `水面粗糙度` | 水面高度差转为法线坡度的倍率。 |
| `倒影扰动强度` | 水面坡度对倒影采样偏移的强度。 |
| `风纹高光强度` | 风纹产生的额外高光强度。 |

### 脚步涟漪

脚步涟漪由管理器维护。玩家脚本中调用：

```gdscript
积水管理器.添加脚步涟漪(global_position)
```

节点参数控制速度、持续时间、圆环宽度、强度和高光。管理器最多同时维护 `16` 个脚步涟漪。

### 雨滴涟漪

雨滴涟漪完全独立于脚步涟漪，可通过 `启用雨滴涟漪` 开关。其余参数分别控制雨滴间距、生成间隔、扩散速度、持续时间、宽度、强度和高光。关闭开关后不会执行雨滴波纹计算。

## 积水水面

积水水面适合河面、湖面等本来就存在的水域，不参与动态积水遮罩。

1. 添加插件提供的 `积水水面` 自定义节点。
2. 将 `Sprite2D`、`Polygon2D`、`TileMapLayer` 或其他 `CanvasItem` 挂到它下面，层级深度不限。
3. 容器会自动创建 `shader/固定水面.gdshader` 材质，并让所有后代使用父材质。
4. 节点会自行向管理器注册；动态添加的后代也会自动继承材质和倒影纹理，不再使用全局分组。

积水水面的参数统一在节点检查器中调整，并按“水面外观”“倒影”“风吹水纹”“雨滴涟漪”分组。关闭倒影、风扰动或雨滴涟漪后，对应的从属参数会自动隐藏；倒影纹理由管理器在运行时注入，不需要手动设置 Shader 参数。
- `ripple_highlight`：风纹高光。
- `rain_ripples_enabled` 及对应 `rain_ripple_*` 参数：固定水面的雨滴涟漪。

倒影使用管理器创建的动态 `SubViewport`，不需要在场景中预先放置倒影视口。倒影层是管理器常量，默认为第 `20` 层；需要显示倒影的节点及其 `CanvasItem` 内容必须位于该层。

## 管理器接口

```gdscript
# 判断世界坐标是否位于当前动态积水内
if 积水管理器.is_point_in_water(global_position):
	积水管理器.添加脚步涟漪(global_position)

# 让节点跟随主视口的画布变换
积水管理器.绑定视口跟随(节点)
积水管理器.解除视口跟随(节点)

# 获取倒影视口动态纹理
var 纹理: ViewportTexture = 积水管理器.获取倒影纹理()
```

## 常见问题

### 没有生成积水

- 确认插件已启用，且 `/root/积水管理器` 存在。
- 确认场景中只有一个积水画布，并且该节点已进入场景树。
- 检查 `启用全图噪声积水`、`启用指定区域积水` 和 `干涸度`。
- 如果只使用指定区域，请创建 `积水区域` 节点，将类型设为“生成”并绘制多边形。

### 水面没有倒影

- 确认倒影对象所在的 CanvasItem 图层包含第 `20` 层。
- 积水水面材质使用 `固定水面.gdshader`，并启用 `reflection_enabled`。
- 不要把倒影视口纹理直接写死到场景资源，纹理由管理器运行时注入。

### 导入其他项目后脚本报错

- 必须复制完整的 `addons/积水系统` 目录，包括 `shader` 和 `脚本` 子目录。
- 检查 Shader 路径为 `res://addons/积水系统/shader/积水.gdshader`。
- 在项目设置中确认 Autoload 名称严格为 `积水管理器`。
- 修改插件文件后重启 Godot，让编辑器重新扫描资源。

### 水面模糊或性能不足

- 降低 `倒影扰动强度`、`水面粗糙度` 或风纹高光。
- 如果移动时出现遮罩边缘，可提高 `遮罩精度` 或 `遮罩缓冲比例`；每侧固定缓冲为 `256` 世界单位。视口较小时建议将 `遮罩精度` 提高到 `512`。
- 关闭不需要的雨滴涟漪。
- 大型场景首次生成遮罩会使用后台线程，但节点实例化和 GPU 上传仍在主线程执行。
